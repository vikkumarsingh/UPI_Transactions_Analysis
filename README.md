# Bank Financial Transactions & Monthly Trends Analysis Dashboard

## 📌 Project Overview
This **Power BI Dashboard** provides a comprehensive analysis of financial transaction patterns, volume fluctuations, and currency balance dynamics across major metropolitan cities for the Year 2024. Designed with extensive interactive slicing capabilities, this dashboard enables stakeholders to examine transaction trends by banking institutions, merchant categories, user demographics, payment channels, and operational locations.

---

## 📊 Key Highlights & Data Insights

### 📈 Monthly Transaction Volumes (2024 Trends)
* **Peak Volume:** **May** recorded the highest transaction count at **1,707K**[cite: 5].
* **Secondary Peaks:** **February** (**1,693K**) and **October** (**1,691K**) experienced significant activity surges[cite: 5].
* **Lowest Volume:** **August** marked the lowest transaction period at **1,599K**[cite: 5].
* **Consistency:** Overall transaction volumes maintained a stable baseline between **1.59M and 1.70M per month** throughout the year[cite: 5].

### 🏛️ Regional & Currency Breakdown
* **Bangalore (EUR):** Recorded transaction amounts peaking at **1,623,693 (March)**, **1,609,833 (July)**, and **1,641,810 (November)** with dynamic account balances maintained around **€8.2M - €8.3M**[cite: 6].
* **Delhi (USD):** Showed strong volume activity in **February ($1,692,738)**, **June ($1,652,588)**, and **October ($1,691,413)** with remaining balances hovering around **$8.35M - $8.53M**[cite: 6].
* **Hyderabad (GBP):** Highlighted operational transaction volumes in **April (£1,662,907)**, **August (£1,598,709)**, and **December (£1,646,019)** with balances near **£8.4M**[cite: 6].
* **Mumbai (INR):** Generated high domestic transaction values in **January (₹1,678,735)**, **May (₹1,706,786)**, and **September (₹1,667,044)** maintaining reserves around **₹8.2M - ₹8.4M**[cite: 6].

## 🛠️ Interactive Slicers & Filtering Dimensions

The dashboard is equipped with **10 dynamic slicers** for multi-dimensional deep dives:
1. **BankNameSent:** Filter by originating banking institution[cite: 5, 6].
2. **BankNameReceived:** Filter by beneficiary banking institution[cite: 5, 6].
3. **City:** Focus on specific geographical markets (Bangalore, Delhi, Hyderabad, Mumbai)[cite: 5, 6].
4. **DeviceType:** Segment transactions by platform (Mobile, Desktop, Tablet, Web)[cite: 5, 6].
5. **Gender:** Demographic breakdown by user gender[cite: 5, 6].
6. **Age Group:** Demographic categorization across age brackets[cite: 5, 6].
7. **MerchantName:** Filter by receiving commercial entities and vendors[cite: 5, 6].
8. **PaymentMethod:** Analyze channels (UPI, Credit Card, Debit Card, Net Banking)[cite: 5, 6].
9. **Purpose:** Categorize transactions by usage intent[cite: 5, 6].
10. **TransactionType:** Drill down into specific transfer mechanisms[cite: 5, 6].
